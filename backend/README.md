A comprehensive job connection platform API connecting verified job seekers with trusted agents and employers across Nigeria.

## 🚀 Features

- **User Management**: Registration, login, profile management
- **Job Listings**: Create, search, and manage job postings
- **KYC Verification**: BVN, NIN, and address verification
- **Commission System**: Track agent commissions and payments
- **Admin Dashboard**: Full platform management and monitoring
- **Communication**: In-app messaging, broadcasts, email notifications
- **GPS Tracking**: Location verification for users
- **Testimonials**: User reviews and ratings
- **Analytics**: Platform statistics and reporting
- **Audit Logs**: Track all platform activities

## 📋 Tech Stack

- **Backend**: Python 3.11+, Flask 2.3+
- **Database**: PostgreSQL (Supabase)
- **Email**: SendGrid
- **KYC**: Identitypass API
- **Deployment**: Render
- **Security**: bcrypt, rate limiting, CORS
